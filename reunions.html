Mode d'emploi

Comment utiliser ReunionPro ?

En quelques étapes simples, organisez ou participez à une réunion de l'AITO.

👤 Organiser une réunion

Créer la salle

Cliquez sur "Créer une réunion" dans l'application ci-dessus. Une salle sécurisée est générée instantanément.

Inviter les membres

Partagez le lien ou le code via le bouton WhatsApp. Vos invités reçoivent automatiquement les informations de connexion.

Démarrer la réunion

Activez votre caméra et votre micro, puis attendez que les participants rejoignent. La réunion est enregistrée automatiquement.

Accéder aux archives

L'enregistrement cloud est disponible après la réunion via Daily.co. Conservez les comptes rendus vidéo indéfiniment.

👥 Rejoindre une réunion

Recevoir l'invitation

L'organisateur vous envoie un lien ou un code via WhatsApp, email ou SMS.

Rejoindre la salle

Cliquez sur le lien ou entrez le code dans le champ "Rejoindre" de l'application ci-dessus.

Autoriser l'accès

Accordez l'accès à votre caméra et micro lorsque le navigateur le demande. Sur mobile, suivez la redirection.

Participer

Vous êtes connecté ! Utilisez les contrôles vidéo/audio pour gérer votre participation durant la réunion.
